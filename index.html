💾 Backup Automático (nuvem)

Toda alteração que você faz é enviada em tempo real para a nuvem — se abrir o sistema em outro computador com o mesmo login, os dados já estarão lá, atualizados. Além disso, o sistema guarda uma cópia completa automaticamente uma vez por dia (últimos 30 dias). Você também pode gerar uma cópia manual a qualquer momento.

📁 Backup Local (arquivo no seu PC)

Uma segunda camada de segurança, independente da internet: baixa um arquivo com todos os dados do sistema. Guarde num pendrive, na nuvem pessoal (Google Drive/OneDrive) ou mande pra você mesmo no celular por WhatsApp/e-mail. Se um dia precisar, é só restaurar esse arquivo aqui.
